# ჰერეთი — მეხსიერების მიწა

ქართული ენის ისტორიული ციფრული ატლასი ჰერეთის შესახებ.

## GitHub Pages-ის ჩართვა

1. გახსენით repository-ის **Settings**.
2. გადადით **Pages** განყოფილებაში.
3. `Build and deployment`-ში აირჩიეთ **Deploy from a branch**.
4. Branch აირჩიეთ `main`, folder — `/ (root)`, შემდეგ დააჭირეთ **Save**.
5. რამდენიმე წუთში საიტი გამოჩნდება Pages-ის მისამართზე.

## შენიშვნა

ამჟამინდელი რუკა სქემატურია, ხოლო ტაძრების ზოგი ფოტო საილუსტრაციოა და არა კონკრეტული ძეგლის დადასტურებული ფოტო. საბოლოო ვერსიაში უმჯობესია ჩაისვას ზუსტი რუკები, სანდო წყაროები და შენ მიერ მოწოდებული ტაძრების ფოტოები.
